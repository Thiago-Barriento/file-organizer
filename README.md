# 📂 Automatic File Organizer (Python)

A Python automation project that organizes files automatically based on their file extensions.

This tool is ideal for personal use or small businesses, helping keep folders such as Downloads or work directories clean and well organized.

---

## 🚀 Features

- Automatically organizes files by type
- Creates destination folders if they do not exist
- Supports common file formats:
  - PDFs
  - Images
  - Documents
  - Spreadsheets
  - Audio files
  - Video files
  - Compressed files
- Clean, modular, and easy-to-maintain code
- Great project for automation and Python portfolios

---

## 🧠 How It Works

1. The user provides a folder path
2. The program scans all files inside the folder
3. Files are categorized by extension
4. Folders are created automatically
5. Files are moved to their respective directories

---

## 🛠️ Technologies Used

- Python 3
- Standard libraries:
  - `os`
  - `shutil`
